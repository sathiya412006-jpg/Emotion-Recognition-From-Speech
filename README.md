# Emotion Recognition from Speech

## CodeAlpha Internship Project

### Objective
Recognize human emotions from speech audio using deep learning and speech signal processing techniques.

### Technologies Used
- Python
- TensorFlow
- Librosa
- NumPy
- Scikit-learn
- Matplotlib

### Deep Learning Model
- LSTM Neural Network

### Features
- MFCC Feature Extraction
- Audio Signal Processing
- Emotion Classification
- Accuracy Evaluation
- Confusion Matrix
- Accuracy Graph

### Dataset
RAVDESS Emotional Speech Audio Dataset

### Emotions Detected
- Happy
- Sad
- Angry
- Fearful
- Neutral
- Calm
- Disgust
- Surprised

### Run Command
python emotion_recognition.py
